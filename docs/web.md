# Web 契约索引

Web 的当前详细架构和 API 消费说明位于 [`docs/decisions/web.md`](decisions/web.md)。站点设置（`GET /api/v1/site`）驱动公开站点身份与首页组合：`title`/`description` 驱动浏览器标题与 SEO/RSS 元数据，`navigation` 驱动顶部导航（空回退内置三项），`footer`/`social` 驱动页脚底行与链接，`commentsEnabled=false` 时详情页不渲染评论区（Core 公开评论接口同时 403 兜底），`sections`（`PROFILE/BACKGROUND/RECENT_CONTENT/UPDATES/SERIES/CONTACT` 枚举）驱动首页区块内容与顺序（锚点与编号随之派生），首页内容列按发布时间排序展示。首页其余结构包含 Background 的 Education/Experience 双列区块、左右双栏 Writings/Thoughts 时间线（各最多 3 条）、最近 10 个内容更新的等距月份 Updates 轨道、可按年份切换的 GitHub 风格 Contribution activity、My Series 索引卡片与纯图标 Contact rail（`profile.websiteUrl` 渲染为首个 Website 图标条目）；Series/Contact 详情使用挂载到 `document.body` 的最高层级 tooltip，内容仍由 Core 驱动。Thoughts 归档直接消费 Core 计算的置顶项、分页、`tag`/`q` 过滤（多 tag 按 OR 命中）、正文摘录和点赞/观看/未软删评论数，Web 只把当前页按 UTC 年份/月份/日期组织成分块时间轴，年份为卡片 surface 之外的分节标题行，并在置顶与时间轴之间提供同款搜索与 tag 过滤（状态同步到 URL）；Writings 归档提供搜索、tag、排序、No AI 开关和分页，全部由 Core 数据层执行。两个归档共用 `useArchiveFilters` 客户端数据流：首屏由 Server Component 读取，后续筛选/翻页由 SDK 请求对应页并以 `history.replaceState` 同步 URL；置顶卡只在默认视图（无 `q`/`tag`/`noAi` 且 `sort=newest`）展示，Writings 归档改请求 `writings()` aggregate，`data`/`totalItems` 由 Core 排除置顶项（与 Thoughts 归档同口径）；tag 云与计数来自 `/api/v1/tags`，两页均提供 `View all tags` 弹出选择器（视口全局居中的固定面板）：展示全部 tag、允许多选（即时生效、点空白处或 Escape 关闭），选中的 tag 在 tag 云中浮动到最前（writings 顶部、thoughts 最左）。默认着陆视图首屏仅展示页头、置顶卡与底部居中的呼吸式下滑箭头提示，底部列表在用户手动滚动到位后才浮现（箭头可点击平滑下滑一屏，列表浮现的同时淡出）；筛选或排序状态下列表按 IntersectionObserver 逻辑自动浮现。Thoughts 与 Writings 卡片均把星号灰色摘要和正文摘录分开，普通项显示两行正文、置顶项显示四行。文章详情在标题阅读面上方单独显示返回 Writing 的入口，正文区域使用四段同宽的不透明阅读面、同排元数据、右侧标题进度目录；底部讨论面提供统计、搜索和筛选，添加评论面承载互动与表单，桌面/平板由左侧紧凑动作卡通过共享布局动画移入，越过激活线后继续下滑保持底部状态，仅向上越回激活线才恢复左侧，布局变化时自动重算，手机端在讨论面之后堆叠。Thought 详情复用同一纸面语言但不使用阅读壳：标题面以 ✦ 灰色摘要、mood 徽标与点赞/观看/评论计数呈现 Thought 语境，question 以 serif 反思引言块突出，context/source 作 mono 脚注，标题面与正文面之间提供复用 Writing 目录轨道视觉的阅读进度轨（宽屏为正文右侧吸附竖轨，≤1300px 退化为正文面上方的横向进度行），讨论面与添加评论面作为两个独立块直接置于正文面下方。两个详情页共用统一的评论渲染：点阵头像（按种子确定性生成）、微信式左下尖角气泡、相对时间、hover 淡入的回复按钮与两级缩进的嵌套回复，评论身份（组合词默认名 + 可点选头像）保存在浏览器本地；讨论面按顶层评论分页（每页 10 条，回复随顶层同页，`q` 服务端线程级搜索），分页器与两个归档共用 `components/pagination.tsx` 且单页隐藏；评论提交经过"遮罩转圈 → 对勾成功面板（View your comment 跳转新评论 / Comment again 再次编辑）"的状态流，成功面板持续停留直至用户操作，发布顶层评论后自动清空搜索并跳到最后一页。共同信息的展示参考根目录 `1.html`。全局导航提供 route-aware pills、⌘K/Ctrl+K 搜索、主题切换、RSS 与站点设置的外链。两个详情页均为 Dynamic Server Component，渲染时经 `next/headers` 读取 `referer` 并以 origin 形式传给 `contentBySlug` 的 `referrer` 参数，供 Core 浏览事件做来源分析；访客 ID 镜像到 `manifold-vid` cookie 后由详情页 SSR 附带 `X-Visitor-ID`，浏览事件按访客去重；`generateMetadata` 仍以 `trackView:false` 读取避免重复计数。

本文只保留入口，避免 `docs/web.md` 与决策目录中的 Web 契约出现两份不一致的事实。修改 Web 路由、Core 请求、Markdown 渲染、评论/反应、SEO 或设计约束时，必须同步 `docs/decisions/web.md`，并检查本索引是否仍准确。
