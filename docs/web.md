# Web 契约索引

Web 的当前详细架构和 API 消费说明位于 [`docs/decisions/web.md`](decisions/web.md)。首页当前包含 Profile/Introduction、左右双栏 Writings/Thoughts 时间线、最近 10 个内容更新的等距月份 Updates 轨道、可按年份切换的 GitHub 风格 Contribution activity、My Series 索引卡片与纯图标 Contact rail；Series/Contact 详情使用挂载到 `document.body` 的最高层级 tooltip，内容仍由 Core 驱动。Thoughts 归档直接消费 Core 计算的置顶项、分页、`tag`/`q` 过滤（多 tag 按 OR 命中）、正文摘录和点赞/观看/已审核评论数，Web 只把当前页按 UTC 年份/月份/日期组织成分块时间轴，年份为卡片 surface 之外的分节标题行，并在置顶与时间轴之间提供同款搜索与 tag 过滤（状态同步到 URL）；Writings 归档提供搜索、tag、排序、No AI 开关和分页，全部由 Core 数据层执行。两个归档共用 `useArchiveFilters` 客户端数据流：首屏由 Server Component 读取，后续筛选/翻页由 SDK 请求对应页并以 `history.replaceState` 同步 URL；置顶卡只在默认视图（无 `q`/`tag`/`noAi` 且 `sort=newest`）展示，此时列表请求以 `skipFirst` 排除置顶条目；tag 云与计数来自 `/api/v1/tags`，两页均提供 `View all tags` 弹出选择器（视口全局居中的固定面板）：展示全部 tag、允许多选（即时生效、点空白处或 Escape 关闭），选中的 tag 在 tag 云中浮动到最前（writings 顶部、thoughts 最左）。默认着陆视图首屏仅展示页头、置顶卡与底部居中的呼吸式下滑箭头提示，底部列表在用户手动滚动到位后才浮现（箭头可点击平滑下滑一屏，列表浮现的同时淡出）；筛选或排序状态下列表按 IntersectionObserver 逻辑自动浮现。Thoughts 与 Writings 卡片均把星号灰色摘要和正文摘录分开，普通项显示两行正文、置顶项显示四行。文章详情在标题阅读面上方单独显示返回 Writing 的入口，正文区域使用四段同宽的不透明阅读面、同排元数据、右侧标题进度目录；底部讨论面提供统计、搜索和筛选，添加评论面承载互动与表单，桌面/平板由左侧紧凑动作卡通过共享布局动画移入，越过激活线后继续下滑保持底部状态，仅向上越回激活线才恢复左侧，布局变化时自动重算，手机端在讨论面之后堆叠。共同信息的展示参考根目录 `1.html`。全局导航提供 route-aware pills、⌘K/Ctrl+K 搜索、主题切换、RSS 与 GitHub 外链。

本文只保留入口，避免 `docs/web.md` 与决策目录中的 Web 契约出现两份不一致的事实。修改 Web 路由、Core 请求、Markdown 渲染、评论/反应、SEO 或设计约束时，必须同步 `docs/decisions/web.md`，并检查本索引是否仍准确。
