# Web 契约索引

Web 的当前详细架构和 API 消费说明位于 [`docs/decisions/web.md`](decisions/web.md)。站点设置（`GET /api/v1/site`）驱动公开站点身份与首页组合：`title`/`description` 驱动浏览器标题与 SEO/RSS 元数据，`navigation` 驱动顶部导航（空回退内置四项（Home/Writings/Thoughts/Chain）），`footer`/`social` 驱动页脚底行与链接，`commentsEnabled=false` 时详情页不渲染评论区（Core 公开评论接口同时 403 兜底），`sections`（`PROFILE/BACKGROUND/RECENT_CONTENT/UPDATES/SERIES/CONTACT` 枚举）驱动首页区块内容与顺序（锚点随之派生），首页内容列按发布时间排序展示；hero headline 下渲染一行 mono 统计（`articleCount/thoughtCount/wordCount` 的 `N writings · N thoughts · N words`）。首页其余结构包含 Background 的 Education/Experience 双列区块、左右双栏 Writings/Thoughts 时间线（各最多 3 条，每行在相对日期与阅读时长下渲染 `views · likes · comments` 统计，不再叠加绝对日期；双列下方渲染 `tags()` 前 8 个标签的 Top tags 展示行，tags 请求独立降级）、按 `publishedAt` 升序铺满 Core 返回的最新范围的横向 Updates 轨道（月份刻度下带春/夏/秋/冬季节色带；顶部地图缩放式按钮（区块头部右侧，与 hint 同排）展开面板：连续滑块（0–100）平滑缩放窗口（默认最近 7 天，锚定最新内容），Reset 恢复默认最近 7 天窗口，窗口内容重新拉伸撑满整条轨道，标签按轨道宽度自动减密；头部 hint 显示 `{contentCount} notes · {wordCount} words`）、My Series 索引卡片与纯图标 Contact 卡（实底 paper + hairline + 8px 圆角，与 Series 同语言；`profile.websiteUrl` 渲染为首个 Website 图标条目）；桌面区块间距统一 72px、≤768px 收窄为 44px。Series/Contact 详情使用挂载到 `document.body` 的最高层级 tooltip，内容仍由 Core 驱动。Thoughts 与 Writings 归档都通过 `content()` 按 kind 请求 Core 分页、`tag`/`q` 过滤、正文摘录和互动计数；Writings 额外支持排序与 No AI 过滤。两个归档共用 `useArchiveFilters` 客户端数据流：首屏由 Server Component 读取，后续筛选/翻页由 SDK 请求对应页并以 `history.replaceState` 同步 URL；置顶卡来自站点组合的 `pinnedThoughts` / `pinnedWritings`，只在默认视图展示，普通列表仍使用 Core `/content` 分页结果；tag 云与计数来自 `/api/v1/tags`，两页均提供 `View all tags` 弹出选择器（视口全局居中的固定面板）：展示全部 tag、允许多选（即时生效、点空白处或 Escape 关闭），选中的 tag 在 tag 云中浮动到最前（writings 顶部、thoughts 最左）。默认着陆视图首屏仅展示页头、置顶卡与底部居中的呼吸式下滑箭头提示，底部列表在用户手动滚动到位后才浮现（箭头可点击平滑下滑一屏，列表浮现的同时淡出）；筛选或排序状态下列表按 IntersectionObserver 逻辑自动浮现。Thoughts 与 Writings 卡片均把星号灰色摘要和正文摘录分开，普通项显示两行正文、置顶项显示四行。文章详情在标题阅读面上方单独显示返回 Writing 的入口，正文区域使用四段同宽的不透明阅读面、同排元数据、右侧标题进度目录；底部讨论面提供统计、搜索和筛选，添加评论面承载互动与表单，桌面/平板由左侧紧凑动作卡下滑淡出、底部添加评论面淡入（独立 layoutId，无跨位置布局动画），默认收起仅显示动作行（GitHub/Guest 登录图标、点赞、评论、分享），越过激活线后继续下滑保持底部状态，仅向上越回激活线才恢复左侧，布局变化时自动重算，手机端在讨论面之后堆叠。Thought 详情复用同一纸面语言但不使用阅读壳：标题面以 ✦ 灰色摘要、mood 徽标与点赞/观看/评论计数呈现 Thought 语境，question 以 serif 反思引言块突出，context/source 作 mono 脚注，标题面与正文面之间提供复用 Writing 目录轨道视觉的阅读进度轨（宽屏为正文右侧吸附竖轨，≤1300px 退化为正文面上方的横向进度行），讨论面与添加评论面作为两个独立块直接置于正文面下方。两个详情页共用统一的评论渲染：点阵头像（按种子确定性生成，GitHub 登录评论则用账号头像 URL 并附 `via GitHub` 徽标）、微信式左下尖角气泡、相对时间、hover 淡入的回复按钮与两级缩进的嵌套回复；评论身份（组合词默认名 + 可点选头像，或 GitHub 登录）保存在浏览器本地，GitHub 会话也可在动作行的 GitHub/Guest 图标间随时切换发布身份（访客模式提交不携带 GitHub Bearer，Core 记录为 visitor）；讨论面按顶层评论分页（每页 10 条，回复随顶层同页，`q` 服务端线程级搜索），分页器与两个归档共用 `components/ui/pagination.tsx` 且单页隐藏；评论提交经过"遮罩转圈 → 对勾成功面板（View your comment 跳转新评论 / Comment again 再次编辑）"的状态流，成功面板持续停留直至用户操作，发布顶层评论后自动清空搜索并跳到最后一页。共同信息的展示参考根目录 `1.html`。全局导航提供 route-aware pills、⌘K/Ctrl+K 搜索、主题切换、RSS 与站点设置的外链。全局模拟终端以 macOS zsh 窗口呈现，首次打开时才以每页 100 条并行遍历全部公开 Writings 与 Thoughts，并与站点描述、关注项和 social 链接共同挂载为 `/Users/manifold` 下的只读文件树；支持目录导航、文件读取、页面打开、系统身份、日期、主题、清屏和退出命令，桌面居中、移动端全屏。搜索面板、阅读面图片预览与模拟终端是三个模态表面，共用 `components/ui/use-modal-focus.ts` 的焦点陷阱与关闭后焦点归还（`role="tooltip"` 浮层不是模态，不陷阱焦点）。两个详情页均为 Dynamic Server Component，渲染时经 `next/headers` 读取 `referer` 并以 origin 形式传给 `contentBySlug` 的 `referrer` 参数，供 Core 浏览事件做来源分析；访客 ID 镜像到 `manifold-vid` cookie 后由详情页 SSR 附带 `X-Visitor-ID`，浏览事件按访客去重；`generateMetadata` 仍以 `trackView:false` 读取避免重复计数。

首页 Recent Content 每类读取 10 条公共内容后展示最近 3 条；Updates 通过 SDK `homeTimeline()` 一次读取 Core 的轻量、有限时间线投影（取最新内容后按首发时间升序），不在 Web 内循环抓取内容分页；截断时页面显示返回范围。RSS 使用独立的小页内容读取，不请求首页时间线聚合。

评论隐藏由 Core 返回的 `Comment.hidden` 表示：未软删的隐藏行保留线程位置，但公开响应不包含作者名、网站、正文或头像种子，Web 渲染固定占位符 `This comment was hidden by moderation.`；隐藏不级联回复，隐藏行也不参与公开搜索或 `comment_count`。评论相关事实以 `docs/decisions/web.md` 和 `docs/core.md` 为准。

`/chain` 是轻量锚定链入口（契约见 [`docs/chain.md`](chain.md)）：保留 1080px shell、`Height`/`Commitments`/`Proof`/`Site key` 概览、genesis/tip 状态和最近活动，并以 `◇ Chain map` 提供两个明确入口。`/chain/explorer` 负责 Blocks/Certificates 两个页签：区块和证书列表支持分页，证书支持 source/ref 筛选，点击项在同一页打开详情；详情状态、筛选和页码通过 URL 保存，区块可进入证书，证书可打开目标或跳转 Tools 验证。`/chain/tools` 负责 Verify/Submit 两个页签，保留 payload、SHA-256、slug、comment 四种验证入口、Core 全链重放、公开提交、限流/冷却和 pending 记录。Explorer 与 Tools 页头使用同源历史返回，内容详情页的 `AnchorBadge` 分别深链到对应区块或提交页；旧 `/chain?block=<id>`、`/chain?page=N` 链接服务端兼容导向 Explorer。所有哈希/规范化仍由 Core 完成，Web 不复制链逻辑。

Web 由 `app/web/proxy.ts` 下发带 per-request nonce 的 `Content-Security-Policy`（`script-src` 不含 `'unsafe-inline'`），访客会话与 OAuth cookie 在 TLS 下带 `Secure`；具体指令、matcher 排除规则和 cookie 属性判定见 [`docs/decisions/web.md`](decisions/web.md) 第 6 节。

本文只保留入口，避免 `docs/web.md` 与决策目录中的 Web 契约出现两份不一致的事实。修改 Web 路由、Core 请求、Markdown 渲染、评论/反应、SEO、安全边界（CSP、cookie 属性）或设计约束时，必须同步 `docs/decisions/web.md`，并检查本索引是否仍准确。
